## 1. Smart Parse

### Happy Path

- [ ] Отправить боту: `позвонить Ивану завтра` → Ожидание: задача создана с названием "позвонить Ивану", дата = завтра, статус = active
- [ ] Отправить: `купить молоко #products` → Ожидание: задача создана, тег #products привязан (проверить в веб-приложении)
- [ ] Отправить: `подготовить отчёт в пятницу в 15:00 #work` → Ожидание: задача с датой = ближайшая пятница, время 15:00, тег #work
- [ ] Отправить: `купить билеты через 2 дня` → Ожидание: задача с датой = сегодня + 2 дня
- [ ] Отправить: `встретиться 15 июля` → Ожидание: задача с датой = 15 июля
- [ ] Отправить: `на следующей неделе #trip` → Ожидание: задача с датой = ближайший понедельник, тег #trip
- [ ] Отправить: `done task tomorrow #test` → Ожидание: задача "done task" с датой завтра, тег #test (не reply action, т.к. не ответ на сообщение)

### Fallback

- [ ] Отправить: `просто текст без паттернов` → Ожидание: задача во входящих (inbox), без даты, без тегов
- [ ] Отправить: `в магазине #errands` → Ожидание: "в магазине" НЕ распознаётся как дата, задача во входящих с тегом #errands

### Краевые случаи

- [ ] Отправить: `#tag` (только тег, без текста) → Ожидание: задача с названием "#tag" во входящих (fallback)
- [ ] Отправить: `завтра завтра завтра` → Ожидание: одна дата завтра, название без дублей "завтра"
- [ ] Проверить подтверждение в боте: в сообщении-подтверждении отображается 📅 дата и 🏷 теги
- [ ] Проверить в веб-приложении: задача создалась корректно, тег/дата совпадают

## 2. Reply Actions

### Предусловие

- Отправить `/today` или `/inbox` — бот присылает список задач
- ИЛИ отправить текст для создания задачи (quick add) — бот присылает подтверждение

### Happy Path

- [ ] Ответить (reply) на подтверждение создания задачи текстом `done` → Ожидание: "✅ Задача «...» → выполнена"
- [ ] Ответить (reply) на подтверждение создания задачи текстом `готово` → Ожидание: то же самое
- [ ] Создать задачу, ответить на подтверждение `завтра` → Ожидание: "📅 Задача «...» → перенесена на завтра"
- [ ] Создать задачу, ответить на подтверждение `сегодня` → Ожидание: "📅 Задача «...» → перенесена на сегодня"
- [ ] Создать задачу, ответить на подтверждение `удалить` → Ожидание: "🗑️ Задача «...» → удалена"
- [ ] Создать задачу, ответить на подтверждение `inbox` → Ожидание: "📥 Задача «...» → во входящих"

### Краевые случаи

- [ ] Ответить (reply) `done` на сообщение, которому больше 7 дней → Ожидание: ничего не происходит (mapper истёк)
- [ ] Ответить (reply) `какой-то случайный текст` на подтверждение задачи → Ожидание: ничего не происходит
- [ ] Написать `done` без reply (обычным сообщением) → Ожидание: создаётся задача "done" во входящих (Smart Parse fallback)
- [ ] После reply action проверить в веб-приложении: изменение применилось (статус, дата)

### Precedence

- [ ] Ответить (reply) `завтра` на подтверждение задачи → Ожидание: это reply action (перенос), а НЕ создание новой задачи "завтра"

## 3. /stats

### Happy Path

- [ ] Отправить `/stats` → Ожидание: сообщение со статистикой за 7 дней
  - Эмодзи-бар (█░) отображается
  - Streak показывает число
  - Если есть завершённые задачи с проектами — топ-3 проектов
- [ ] Нажать inline-кнопку "📅 За месяц" → Ожидание: сообщение обновляется на статистику за 30 дней
- [ ] Нажать inline-кнопку "📅 За неделю" → Ожидание: сообщение обновляется на статистику за 7 дней

### Краевые случаи

- [ ] Новый пользователь без задач → Отправить `/stats` → Ожидание: "Пока нет данных"
- [ ] Пользователь с задачами, но без завершённых → Ожидание: бар пустой (░░░░░░░░░░), streak = 0
- [ ] Проверить что `/stats` указан в `/help`

## 4. Daily Digest

### Настройка через API

- [ ] `GET /api/users/me/digest` → Ожидание: `{"enabled": false, "time": "08:00"}`
- [ ] `PUT /api/users/me/digest` с `{"enabled": true, "time": "08:00"}` → Ожидание: `{"enabled": true, "time": "08:00"}`
- [ ] Установить время на 1 минуту вперёд от текущего → подождать → Ожидание: бот присылает утреннюю сводку
- [ ] Проверить что сводка содержит: приветствие, задачи на сегодня, просроченные, входящие

### Содержание сводки

- [ ] Сводка содержитinline-кнопки "📋 Все задачи" и "📥 Входящие"
- [ ] Нажать "📋 Все задачи" → Ожидание: показывается список задач на сегодня
- [ ] Нажать "📥 Входящие" → Ожидание: показывается список входящих

### Защита от дублей

- [ ] Digest пришёл один раз → подождать ещё минуту → Ожидание: второй digest НЕ приходит
- [ ] На следующий день → Ожидание: digest приходит снова

### Краевые случаи

- [ ] `PUT /api/users/me/digest` с `{"enabled": true}` без подключённого бота → Ожидание: ошибка 400 "Telegram bot must be configured"
- [ ] `PUT /api/users/me/digest` с `{"enabled": true, "time": "25:00"}` → Ожидание: ошибка 400 "Invalid time value"
- [ ] `PUT /api/users/me/digest` с `{"enabled": true, "time": "abc"}` → Ожидание: ошибка 400 "Time must be in HH:MM format"
- [ ] Нет задач на сегодня → Ожидание: "На сегодня задач нет. Отличный день!"
- [ ] `PUT /api/users/me/digest` с `{"enabled": false}` → Ожидание: digest перестаёт приходить

## 5. Интеграция

- [ ] Smart Parse + Reply: создать задачу через `купить хлеб завтра #еда`, ответить на подтверждение `done` → задача выполнена, в вебе видно
- [ ] Digest + Reply: получить digest, нажать "📋 Все задачи", ответить на задачу из списка `завтра` → дата обновилась (только если mapping записан)
- [ ] `/stats` после выполнения задач через reply → Ожидание: статистика обновляется
